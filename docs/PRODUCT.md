# 假装一棵树｜产品定义

## 定位

「假装一棵树」是一款极简、本地优先的 Windows 无限白板工具。

核心理念：

> 从一个想法开始。

## 产品决策

| 项目 | 决策 |
| --- | --- |
| 平台 | Windows |
| 账号 | 无账号 |
| 服务端 | 无服务器 |
| 数据 | 全部本地保存 |
| 文件格式 | `.treeboard` |
| 窗口模式 | 单窗口 |
| 导出 | PNG + PDF |
| 交付 | Windows 安装包 |

## 设计原则

1. 极简

首页与编辑器避免复杂导航，优先保证创作开始速度。

2. 本地优先

用户拥有自己的白板文件，不依赖云端。

3. 克制设计

借鉴 Apple 式产品设计理念：减少干扰，让内容成为主体。

## 1.0 功能范围

### 白板编辑

- 无限画布
- 平移与缩放
- Mini Map
- 便签
- 文字
- 基础图形
- 画笔 / 橡皮擦
- 图片导入
- 连接线

### 编辑能力

- 多选
- 组合 / 取消组合
- 锁定
- 对齐
- 分布
- 等宽 / 等高 / 等尺寸
- 层级管理
- 撤销 / 重做

### 文件能力

- `.treeboard` 项目文件
- 自动保存
- 自定义保存位置
- 最近打开
- PNG 导出
- PDF 导出

## 当前阶段

当前版本为 Windows alpha 阶段，重点验证：

- 产品交互
- 文件体系
- 本地保存
- 软件体验

后续版本再逐步增加 Frame、区域管理、更多排版能力等。
