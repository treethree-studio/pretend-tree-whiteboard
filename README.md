# 假装一棵树

> 从一个想法开始。

一个极简、本地优先的 Windows 无限白板工具。

## 产品原则

- Windows 桌面应用
- 无账号、无服务器、无云同步
- 所有白板数据保存在本地
- 专属项目文件格式：`.treeboard`
- 单窗口模式
- 默认保存位置支持自定义
- 自动保存
- 导出 PNG + PDF

## 当前能力

- 无限画布、缩放与平移
- 便签、文字、基础图形
- 画笔与橡皮擦
- 连接线与连接线文字
- 图片批量导入，支持透明 PNG / WebP
- 多选、组合、锁定
- 对齐、分布、等宽 / 等高 / 等尺寸
- 图层顺序、撤销 / 重做
- Mini Map
- 本地 `.treeboard` 保存

## 当前阶段

当前仓库处于 `v0.1.0-alpha` 阶段，用于 Windows 本地版的持续开发与测试。

- 品牌：**假装一棵树**
- 首页文案：**从一个想法开始**
- 当前实现：Electron Windows alpha

> 1.0 的目标是稳定、克制、好用，而不是堆叠功能。

## 目录

```text
app/         桌面应用源码
installer/   Windows 安装 / 卸载脚本
docs/        产品定义、决策与更新记录
dist/        可下载测试版本
prototype/   白板交互原型归档
```

## 数据与隐私

应用不要求登录，不连接业务服务器。白板数据与导入素材默认保存在用户电脑中。
